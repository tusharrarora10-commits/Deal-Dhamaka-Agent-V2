# Multiple Product Links WhatsApp Fix

- Removed the old product-level Description field from Add/Edit Product. Each link option retains its own description.
- Preserved per-link descriptions when editing existing products.
- WhatsApp message templates now render every saved link as a numbered option, with brand + product type, description, price, and URL.
- Removed the legacy global description line from the message to avoid repeating it under the brand.
- Existing single-link products remain supported as a one-option numbered list.
- No storage key or WhatsApp API workflow changed.
