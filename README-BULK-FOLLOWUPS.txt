Deal Dhamaka Agent V2 — Bulk WhatsApp Follow-ups

Added to the supplied source package without changing the existing storage key or dashboard layout.

Feature:
- Tracking page includes Bulk WhatsApp Follow-ups.
- Choose a product and either pending orders (reminder) or ordered records (honest review request).
- Select all eligible recipients or choose individually; search the recipient list.
- Edit the message template. [name] and [product] are replaced per recipient.
- Processes one WhatsApp chat at a time; each chat must be manually reviewed and sent.
- Does not create share records or mark orders as sent/ordered.
- Duplicate phone numbers are shown only once per selected product.

Deployment:
1. Keep a JSON backup of your existing app data.
2. Deploy this ZIP as a Vercel Preview first.
3. Test on iPhone with a small set of test contacts.
4. Confirm product selection, ordered/pending filtering, recipient selection, and WhatsApp prefilled message.
5. Promote to production only after verifying the existing app functions.
