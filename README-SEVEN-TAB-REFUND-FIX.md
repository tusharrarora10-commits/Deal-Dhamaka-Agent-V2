# Seven-tab navigation and multi-link refund correction

- Main navigation: Home, Contacts, Products, Share, Manual, Finance, More.
- Manual Share / Order Entry is now its own page instead of appearing above Tracking.
- More retains History, Tracking, Recipient activity and Settings in that order, with Settings kept separate.
- Refund amount defaults and summary now use the sum of all priced product links when the saved share snapshot is the legacy first-link amount.
- New share and manual-entry records snapshot the sum of all product-link prices.
- Existing localStorage key and Supabase integration are unchanged.

No LOOTLAB files or features are included.
