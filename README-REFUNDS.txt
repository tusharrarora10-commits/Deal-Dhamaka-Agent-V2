REFUNDS TAB — SEPARATE STATUS REGISTERS

The existing Refunds tab has two separate registers above the existing product/contact controls:
1. Refunded Products: saved refunded records with product, recipient, date and amount.
2. Pending Refunds: ordered eligible records not yet marked refunded, with a Mark refunded action.

Both registers use the existing dealDhamakaAgentV2 localStorage data. No new storage key is introduced. Existing selection and bulk controls remain available.
